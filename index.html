Create the client ID (once)

  1. Open Google Cloud Console and create a project (or pick one).
  2. APIs & Services → Library → enable Google Drive API.
  3. APIs & Services → OAuth consent screen → External → app name “Chores”. Add your Gmail as a test user.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID → Web application.
  5. Authorized JavaScript origins (exact origin, no path): https://YOURUSER.github.io. If you test locally, also add http://127.0.0.1:5500 or http://localhost:5500.
  6. Copy the client ID, paste it above, Save ID, then Sign in. The first sign-in creates chores-tracker-data.json in your Drive.
